#### PHP 8 扩展官方支持说明

数据来源:PECL 官网 release 依赖声明,2026-06 核对。

| 扩展    | 官方最新稳定版 | 官方 PHP 依赖声明 | 8.0~8.5 支持说明                         |
| ------- | -------------- | ----------------- | ---------------------------------------- |
| redis   | 6.3.0          | PHP 7.4+          | 单一最新版统一支持 8.0~8.5               |
| yaf     | 3.3.7          | PHP 7.0+          | 单一最新版统一支持 8.0~8.5               |
| mcrypt  | 1.0.9          | PHP 7.2+，≤8.6    | 须 ≥1.0.9 才覆盖 8.5（1.0.7 上限 8.4）   |
| libssh2 | 1.11.1         | 系统 C 库         | 与 PHP 版本无关                          |
| ssh2    | 1.5.0          | PHP 8.0+          | 单一最新版统一支持 8.0~8.5               |
| nsq     | 3.9.1          | PHP 7.0+          | 官方声明支持 8.5，但实际编译失败（见下） |

> 注:nsq 官方最新版为 3.9.1,理论上支持 8.5;但 PHP 8.5 移除了 `php_smart_string_public.h`,源码编译失败,故 8.5 镜像暂不安装,待官方适配后恢复。

## 内置扩展(随 PHP 版本)

bcmath、zip、pdo_mysql、mysqli、opcache、xsl、gettext、pcntl、gd、ldap

> 注:7.1 的 mcrypt 为 PHP 内置扩展,7.2+ 改为 pecl 安装;nsq 在 8.0~~8.4 固定 3.5.1,8.5 因 PHP 移除了 `php_smart_string_public.h` 暂不可用;8.0~~8.4 的扩展版本一致,8.5 除 nsq 外扩展版本与 8.4 相同。
